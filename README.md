# Lesopark Prievidza

Statická webstránka lesoparku na Kopaniciach v Prievidzi – jeden súbor `index.html`, bez buildu.

- 3D les na úvodnej obrazovke (Three.js)
- 3D model areálu zo skutočných dát: terén, lesy, chodníky, budovy, značené trasy
- cenník a kalkulačka rezervácie (dopyt cez SMS / telefón)

**Ceny** sa upravujú na začiatku skriptu v `index.html` (`RENT`, `EXTRAS`). Aktuálne sú orientačné.

Mapové dáta © prispievatelia [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL), výšky: Terrain Tiles (Mapzen / AWS).
